# GoreBox 27 GBMap В PNG
*Конвертирует gbmap в png онлайн.
Кидайте туда файлы формата .gbmap и получайте текстуры и ещё с gbmap.tex и gbmap.nav* ***ЭТО НЕ РАБОТАЕТ,***
*Ведь это другой формат. А сами карты сжаты в gzip и можно достать большинство изображений, хоть некоторые не показываются.
